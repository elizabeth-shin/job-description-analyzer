# Job Description Analyzer

Status: In development.

AI-powered job description analyzer using the Claude API to extract:

- Required skills  
- Seniority signals  
- Role expectations  
- Hidden requirements  
- Resume alignment insights  

## Features
- Paste any job description  
- Claude API extracts structured insights  
- Highlights keywords and competencies  
- Identifies seniority level indicators  
- Suggests resume alignment opportunities
