# Job Description Analyzer

🔗 **Live Demo:** https://elizabeth-shin.github.io/job-description-analyzer/

Status: In development.

An AI‑powered tool that reveals the real signals inside any job description — the skills, competencies, seniority expectations, and hidden requirements that determine whether a candidate is a strong match. Built using the Claude API, this analyzer transforms unstructured job descriptions into structured, actionable insights.

## Why It Exists
Job descriptions are often vague, inconsistent, or overloaded with boilerplate.  
Candidates struggle to understand what a role *actually* requires, and hiring teams often bury the true expectations between the lines.

This tool exposes the underlying structure of a JD — the competencies, seniority markers, and alignment signals — so candidates and teams can make clearer, faster, more informed decisions.

## What It Generates
- **Required skills** and competency clusters  
- **Seniority signals** (scope, autonomy, ambiguity, leadership expectations)  
- **Hidden requirements** not explicitly stated  
- **Keyword extraction** for resume alignment  
- A structured **role summary**  

## Features
- Claude API–powered text extraction and analysis  
- Identification of seniority and scope indicators  
- Keyword + competency mapping  
- Resume alignment insights  
- Clear, structured output for fast interpretation  

## Roadmap
- Resume upload + side‑by‑side comparison  
- Skill gap scoring and recommendations  
- Exportable JD summary (PDF / Markdown)  
- “Rewrite my resume for this role” mode  
- Multi‑JD comparison for job targeting strategy
